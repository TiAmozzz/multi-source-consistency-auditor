# 多源资料一致性核验助手 - 作品介绍正文

## 一、项目概述

多源资料一致性核验助手面向“同一业务实体分散在多份文件、多个表格和不同资料格式中”的核验问题。用户通过配置定义业务编号、字段别名和核验规则，工具将多个来源转换为统一事实记录，按编号归组后检查来源缺失、重复编号、字段冲突、必要字段缺失和日期顺序。

项目以 Agent Skill 作为智能体入口，以 Python 确定性程序作为核心执行引擎。报告生成不依赖在线大模型，相同输入和规则可得到可复现结果。

## 二、项目背景

采购、项目执行、行政归档和资料审查中，同一编号往往同时出现在表格、合同、申请单、验收材料和附件里。人工核对需要逐个打开文件、查找字段、抄录位置，再比较不同来源。资料数量增加后，漏项、金额不一致、孤立文件和重复编号容易被忽略，发现问题后也难以快速定位原文。

普通对话式 AI 可以概括文本，但缺少稳定的解析流程、明确规则和可验证证据。本项目的技术重点是把“找出不同”拆解成可测试的解析、标准化、关联和规则计算。

## 三、技术架构

总体流程为：多来源输入 → 只读快照与哈希 → 格式适配与解析 → 统一事实模型 → 按业务编号关联 → 规则核验 → 用户选择格式的差异汇总。

支持 CSV、TSV、XLSX、XLSM、JSON、DOCX、文本型 PDF、TXT、Markdown 和 HTML。Excel 工作簿中的每个 Sheet 独立读取。

## 四、核心功能

- 同时处理任意数量的表格和文档来源；
- 按业务编号关联一个实体对应的多条记录和多份附件；
- 检查来源覆盖、重复编号、字段冲突、金额容差、必填字段和日期顺序；
- 保留原值、标准化值、文件、Sheet、行号、页码或段落及原文证据；
- 支持 HTML、Excel、Word、PDF、JSON、Markdown 和 CSV 差异汇总；
- 原始资料只读，解析器只处理自动清理的临时副本；
- 运行前后执行 SHA-256 校验，不联网、不上传资料。
- 提供本地文件选择页面，可一次选择多份表格与文档并直接生成指定格式报告。

## 五、应用场景

采购资料交叉审查、合同与申请材料核验、项目附件完整性检查、活动报名与签到资料核对、行政档案目录核对和内部审计前预检。用户通过更换字段和来源配置适配不同业务流程。

## 六、项目创新点

1. 多来源异质资料统一核验，不局限于两张表或固定账本。
2. 可解释规则与原文证据结合，人工可以复核每一条结论。
3. Agent Skill 与确定性引擎分工，避免随机模型判断代替事实计算。
4. 只读临时副本和运行前后哈希形成明确的数据保护边界。
5. 输出格式由用户选择，适应复核、编辑、提交和系统集成。

## 七、测试与运行效果

当前版本实际运行 11 项自动化测试，全部通过。虚构采购样例包含 5 个源文件和 9 条记录，关联出 5 个采购项目；正确识别 1 个金额冲突和 6 个来源缺失警告，源文件运行前后 SHA-256 完全一致。七种输出格式均成功生成有效文件。

## 八、使用限制

核心版本支持可解析的表格和文本型文件；扫描版 PDF 和图片需要 OCR，当前不会在文本为空时猜测内容。文档字段采用“字段名：值”形式，复杂版式可能需要补充别名。规则必须由用户定义，工具不判断材料在法律、财务或业务上的真实性。
