# 多源资料一致性核验助手

## 功能与适用范围

将多个表格或文档来源解析为带证据的事实记录，按同一实体编号归组，执行配置中的确定性核验规则。适用于同一业务实体的多表交叉核对、文件与表格核对、文件目录完整性检查，以及金额、日期、名称和编号差异排查。

本 Skill 只报告规则可计算的事实差异，不判断材料在业务、法律或医学意义上的真实性，也不替代责任人的最终复核。

## 数据安全边界

- 原始资料只读。不得修改、重命名、移动、转换格式或回写源文件。
- 原文件只参与哈希和字节复制；解析器只处理自动清理的临时副本。
- 不得联网、上传、发送或公开任何源文件及报告内容，除非用户另行明确授权具体目标与范围。
- 仅将新生成报告写入用户指定的独立输出目录；输出目录不得位于被扫描的来源目录内。
- 程序中内置源文件 SHA-256 前后核验。若输入被外部修改，报告应出现 `source_file_modified` 严重错误。
- 报告可能包含原文摘录，应按用户的数据敏感级别管理和传递。

## 输入

1. 一个 JSON 配置，定义实体编号、来源、字段别名和核验规则。字段格式见 [references/profile-format.md](references/profile-format.md)。
2. 配置引用的多个来源，支持：
   - 表格：`.csv`、`.tsv`、`.xlsx`、`.xlsm`、`.json`；
   - 文档：`.docx`、文本型 `.pdf`、`.txt`、`.md`、`.markdown`、`.html`、`.htm`。
3. Excel 工作簿中的每个 Sheet 会独立解析。一个文件可按同一实体编号对应多条记录。
4. 扫描版 PDF 和图片不在核心支持范围内；文本提取为空时会产生明确错误。

## 执行步骤

1. 读取配置，确认 `identifier.aliases` 能匹配表格列名，文档字段采用“字段名：值”格式。
2. 确认每类实体都有一个稳定编号。若文件名含编号，可将 `identifier.pattern` 设为对应正则表达式。
3. 从 Skill 目录运行：

   ```bash
   python scripts/audit.py --profile <profile.json> --output <独立输出目录>
   ```

4. 检查命令是否成功以及报告中是否出现 `file_parse_failed`、`missing_identifier` 或 `source_file_modified`。
5. 向用户说明总体状态、错误数、警告数，并优先解释跨来源字段冲突、来源缺失和重复编号。引用证据时必须保留报告中的文件、Sheet、行、页码或段落位置。
6. 用户未允许时，不要打开浏览器自动上传、分享或发布报告，也不要删除已有文件。

## 输出

运行前询问或根据用户要求选择 `--format html`、`--format xlsx`、`--format docx`、`--format pdf`、`--format markdown`、`--format json` 或 `--format csv`，可重复指定多个格式。每个选择生成一份独立的 `differences-summary.<扩展名>` 差异汇总文件：

- HTML：可浏览的汇总、实体对照、问题明细和证据；
- Excel：汇总、问题、实体、证据和来源清单；
- Word：可直接编辑和提交的汇总、实体、差异、证据和来源文档；
- PDF：带分页、页眉页脚和稳定版式的只读汇总文档；
- Markdown：便于复制的汇总与差异报告；
- JSON：机器可读完整结果；
- CSV：一份包含汇总行和差异明细的扁平文件。

所有可用值都保留原始值、标准化值、来源和位置。程序不会用模型猜测替代解析或规则计算。

## 异常处理

- 配置无效：修正 JSON 或字段/来源引用，不运行半成品核验。
- 文件解析失败：报告其余文件结果，同时将该文件标为“解析失败”。
- 缺少编号：将该记录标记为独立未识别项，不与其他记录强行合并。
- 同一来源重复编号：产生 `duplicate_identifier` 错误。
- 来源缺少实体：产生 `source_missing_record`，严重程度由配置决定。
- PDF 无文本：标记为 `empty_or_scanned_document`，提示人工检查或启用用户另行提供的 OCR 流程。

## 使用示例

用户提供“采购台账.xlsx、采购申请.csv 和合同文件夹”，要求检查金额及资料完整性。读取项目仓库中 `examples/procurement/profile.json` 的同类配置，按上述命令运行，然后解释 HTML 报告中的金额冲突、缺失合同和仅存在于合同的孤立记录。示例只使用模拟数据。
